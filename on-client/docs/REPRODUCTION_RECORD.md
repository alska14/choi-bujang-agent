# 22단계 재현 기록과 버전 기록 (Djoković 보안 Agent)

같은 커밋을 별도의 새 빈 폴더에 받아 `docs/STUDENT_RUNBOOK.md` 절차대로 실행한 기록입니다. 이 기록은 학생(저장소 소유자)의 진술이며, 서버가 새 환경에서 실행했다는 뜻이 아닙니다. 서버의 AI 원문 검토도 실행 성공의 증명이 아닙니다.

## 1. 증거의 종류

| 구분 | 뜻 | 이 문서에서 |
|---|---|---|
| 원문 확인 | 파일을 읽고 확인했습니다. 실행하지 않았습니다. | "원문" |
| 모의 점검 | 가짜 DOM에 모의 입력을 넣어 학생 함수를 호출했습니다. 실제 화면이 아닙니다. | "모의" |
| 예제 화면 | `-Demo` 모드의 예제 자료로 실제 화면을 확인했습니다. 예제 판정이며 실제 시스템 연결이 아닙니다. | "예제" |
| 실제 화면(연결 없음) | 기본 실행(어댑터 미연결)에서 실제 화면과 응답을 확인했습니다. 실제 시스템 연결이 아닙니다. | "화면" |

수행 주체: 아래 실행과 화면 확인은 학생의 요청으로 AI 코딩 도구(Claude Code)가 같은 PC에서 실행하고 화면을 읽은 것입니다. 학생이 직접 명령을 입력해 따라 한 재현은 이 기록을 쓴 시점에 하지 않았습니다(미확인). `STUDENT_RUNBOOK.md`의 "PC 실행 확인" 표시도 같은 뜻입니다.
