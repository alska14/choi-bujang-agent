# 보안 관제 화면 안내 (`/pc-status`)

「내 PC 상태」를 보안 관제 센터처럼 키운 화면입니다. 이 PC에서 일어나는 일을 한 화면에 모아 보여 주고, 긴급한 일은 놓치지 않게 알립니다. 값은 모두 이 PC에서 읽은 실측이거나 「확인 불가」이며 예시 값은 쓰지 않습니다. 설정은 바꾸지 않고(읽기 전용), 관리자 권한이 필요한 항목은 읽지 않습니다.

기준: 이 문서는 마지막 총공세 제출 커밋(`99e73fa…`) 뒤에 커밋하지 않은 작업을 설명합니다. 그 커밋의 화면(「다시 조회」·「자동 조회」)과 다릅니다. 이 문서 속 [화면 확인]·[모의 시험] 표시는 2026-10-27 이 PC에서의 확인입니다.

## 열기

```
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-final.ps1
```

- 보안 앱: `http://127.0.0.1:5189/` (오른쪽 아래의 「보안 관제 열기」 링크로 관제 화면에 갈 수 있습니다. 제공된 `public/` 파일은 고치지 않고 서버가 응답에 덧붙입니다. 끄려면 환경변수 `ON_SOC_LINK=0`)
- 보안 관제: `http://127.0.0.1:5189/pc-status`

## 색과 도형

| 표시 | 뜻 |
|---|---|
| ■ 긴급(진한 빨강) | 화면 전체 경고창, 소리, 바탕화면 알림, Windows 팝업. 「확인했음」을 누를 때까지 유지 |
| ◆ 높음(빨강) | 목록 맨 위에 표시. 소리·팝업은 없음 |
| ▲ 주의(노랑) | 목록에만 표시 |
| ◇ 정보(파랑) | 상태 복귀 같은 참고 기록 |
| ● 정상(초록) | 이상 없음 |
| ○ 확인 불가(회색 점선) | 읽지 못했거나 수집하지 않는 항목. 정상이라는 뜻이 아님 |

색뿐 아니라 도형과 글자로도 구분합니다. 평온할 때는 움직임이 없습니다.

## 화면 구성

- 위쪽: 전체 상태(평온·주의·경계·위험·확인 불가), 미확인 사건 수, 소리·바탕화면 알림·시험 경보 버튼.
- 탭 「관제」: 위젯 10개(CPU, 메모리, 디스크, 방화벽·Defender, 실시간 사건, LLM 에이전트 활동, 폴더 변경 감시, 네트워크 보안, 엔드포인트 보안, 계정·접근 관리).
- 탭 「위협 인텔리전스」: 침해지표(IOC)와 전술·기법(ATT&CK) 기반의 수집·공유·탐지·반영 화면.
- 사건은 영역(네트워크 / 엔드포인트 / 계정·접근)으로 나눠 볼 수 있고, 각 사건에서 「확인」(본 것으로 표시)이나 「수용」(오탐이거나 알고 받아들임, 같은 사건을 더 올리지 않음)을 누를 수 있습니다.

## 이상 탐지 규칙

규칙은 사건의 「규칙」 칸에 id와 글로 표시합니다. CPU-HIGH(85% 이상 2회), CPU-CRIT(95% 이상 3회), CPU-SPIKE(40% 이상이며 직전 평균보다 30포인트 이상 높음), MEM-HIGH(85%), MEM-CRIT(92%), MEM-SURGE(8포인트 급증), DISK-LOW(남은 15% 미만), DISK-CRIT(8% 미만), DISK-DROP(5GB 감소). 급증 판정은 기준 표본이 6개 이상 모인 뒤부터입니다.

## 위젯 배치 바꾸기

관제 탭 위쪽의 「배치 편집」을 누릅니다.

- 위젯 위쪽 막대를 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꿉니다. 겹치면 아래로 밀려 빈틈 없이 정리됩니다. 키보드: 막대에 포커스를 두고 방향키는 이동, Shift+방향키는 크기.
- 「숨기기」로 위젯을 숨기고, 「숨긴 위젯 추가」로 되돌립니다.
- 프리셋: 기본 제공 4개(기본 관제, 사건 중심, 자원 감시, 영역별 점검)를 고르거나, 이름을 적고 「현재 배치 저장」으로 내 프리셋을 만듭니다(최대 30개). 바뀐 배치는 자동으로 기억됩니다.
- 저장 위치는 이 브라우저(`localStorage`)입니다. 접속 주소(포트)가 달라지면 따로 저장됩니다. 서버나 다른 PC로는 옮겨지지 않습니다.
- 화면 너비가 1000px 이하면 위젯이 세로로 쌓이고 편집은 꺼집니다.

## PiP·미니 창

화면 위쪽 「PiP·미니 창」에서 설정 서랍을 엽니다. 실시간 미리보기를 보며 정합니다.

- 보여 줄 정보(11가지)를 체크로 켜고 끄고 ↑↓로 순서를 바꿉니다: 전체 상태, 미확인 사건 수, CPU, 메모리, 디스크, 최근 사건 목록, 네트워크·엔드포인트·계정 영역 상태, LLM 에이전트 수집 상태, 마지막 갱신·연결 상태.
- 글자 크기 4단계, 열(창 너비에 맞춤 / 한 줄씩), 창 모양 4가지, 사건 개수·등급·미확인만, 그래프 표시. 프리셋 6개 기본 제공 + 내 프리셋 저장.
- 「PiP 창 열기」: 크롬·엣지 116 이상이면 다른 앱 위에 항상 떠 있는 창(Document Picture-in-Picture)으로 열립니다. 지원하지 않으면 일반 작은 창으로 열리며 항상 위는 아닙니다.
- 긴급 경보 띠는 설정과 관계없이 항상 맨 위에 나타나고, 그 자리에서 「확인했음」을 누를 수 있습니다.
- 확인 상태: 일반 작은 창과 미리보기는 확인했지만, 실제 Document PiP 창은 이 기록 작성 시점의 인앱 브라우저가 창을 만들어 주지 않아 확인하지 못했습니다. 실제 크롬·엣지에서 눌러 보세요.

## 긴급 경보

긴급(■) 사건이 나면 화면 전체 경고창, 소리(켜 두었을 때), 제목 깜빡임, 바탕화면 알림(허락하고 켜 두었을 때. 도구 막대 버튼으로 켜고 끕니다. 브라우저 권한은 한 번 허락하면 페이지가 되돌릴 수 없어서, 켜기·끄기는 앱 설정으로 따로 둡니다), Windows 팝업이 함께 나옵니다. 「시험 경보」 버튼으로 확인합니다. 소리는 브라우저 규칙상 화면을 한 번 누르거나 「소리 꺼짐」 버튼으로 켠 뒤부터 납니다. Windows 팝업은 `ON_SOC_NATIVE_ALERT=0` 이면 뜨지 않습니다(30초에 한 번 제한). Windows 팝업이 실제로 뜨는지는 이 기록 작성 시점에 띄워 보지 않았습니다.

## LLM 에이전트가 파일을 뒤지는 것 보기

Windows는 일반 권한 앱에게 다른 프로그램의 파일 읽기를 알려 주지 않습니다. 그래서 이 화면은 에이전트의 훅(hook)이 남긴 기록만 볼 수 있습니다. 훅이 없으면 「수집 안 함」으로 표시하며, 이것은 안전하다는 뜻이 아닙니다.

켜려면 Claude Code 설정 파일(`settings.json`)의 훅에 `tools\agent-audit-hook.mjs` 를 직접 등록합니다. 이 앱은 사용자의 Claude Code 설정을 자동으로 바꾸지 않습니다. 예시(경로는 본인 PC에 맞게 바꿉니다):

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Read|Glob|Grep|Bash|Edit|Write",
        "hooks": [
          { "type": "command", "command": "node \"C:\\경로\\on-client\\tools\\agent-audit-hook.mjs\"" }
        ]
      }
    ]
  }
}
```

훅은 항상 종료 코드 0으로 끝나고 화면에 아무것도 출력하지 않으며(에이전트의 작업을 막지 않음), 비밀처럼 보이는 값은 가려서 `%LOCALAPPDATA%\djokovic-soc\agent-audit.jsonl` 에 한 줄씩 남깁니다(5MB가 넘으면 회전). 훅 입력 형식은 공식 문서로 확인했으며 이 PC에서 실제 에이전트로 돌려 보지는 않았습니다.

### 다른 PC에서 한 번에 연결(앱의 「이 PC에 감시 연결」)

감사 훅은 PC마다 각 에이전트 설정에 등록해야 합니다. 앱을 새 PC에 설치했으면 「계정·접근」 탭의 LLM 에이전트 활동 칸에서 「이 PC에 감시 연결」을 누르세요. 확인 창 뒤에 훅 스크립트를 `%LOCALAPPDATA%\djokovic-soc\hooks` 에 복사하고, Claude Code(`%USERPROFILE%\.claude\settings.json`)와 Codex CLI(`%USERPROFILE%\.codex\hooks.json`)의 PreToolUse 에 한 항목씩 더합니다. 다른 설정은 그대로 두고 처음 바꾸기 전 원본을 `.djokovic-backup` 으로 남기며, 다시 눌러도 겹치지 않습니다. Node.js 가 없는 PC에서는 Claude Code 훅을 앱 실행 파일(`Djokovic SOC.exe --audit-hook claude`, 약 0.1초)로 실행합니다. Codex 는 Node.js 가 필요하고, 연결 뒤 Codex 의 /hooks 에서 신뢰로 한 번 표시해야 합니다. Claude Code 는 새로 여는 세션부터 기록됩니다.

### Codex CLI 연결

Codex CLI도 같은 훅 형식(PreToolUse)을 지원합니다(2026-10-27 OpenAI 공식 문서 확인, 이 PC는 codex-cli 0.154.0). 앱 폴더에서 한 번 실행합니다.

```
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\install-agent-hooks.ps1
```

- 훅 스크립트 복사본을 `%LOCALAPPDATA%\djokovic-soc\hooks\` 에 두고 `%USERPROFILE%\.codex\hooks.json` 을 만듭니다. 이미 다른 내용의 hooks.json 이 있으면 덮어쓰지 않고 멈춥니다.
- Codex 는 새 훅을 사용자가 확인해야 실행합니다. Codex 를 열고 `/hooks` 에서 이 훅을 신뢰(trust)로 표시해야 기록이 시작됩니다.
- 셸 명령은 비밀값을 가린 명령 앞부분을, 파일 수정(`apply_patch`)은 패치 내용 없이 바뀌는 파일 경로만 남깁니다.
- 지우기: `install-agent-hooks.ps1 -Uninstall`.
- 훅 스크립트에 Codex 모양의 입력을 넣어 기록되는 것까지는 확인했습니다. 실제 Codex 세션으로는 돌려 보지 않았습니다(유료 요청이 생기므로).
- 「계정·접근」 탭의 「감사 훅 연결」 줄에 에이전트별 마지막 기록 시각이 나옵니다. 훅이 없는 에이전트(Gemini CLI 등)는 실행 중인지만 보입니다.

규칙: AGENT-SENSITIVE(긴급: `.ssh`, `.aws`, `.env`, 인증서 키, 브라우저 로그인 데이터 등 민감 경로), AGENT-OUTSIDE(주의: 작업 폴더 밖, 허용 위치는 `ON_SOC_ALLOWED_ROOTS`), AGENT-BURST(높음: 60초에 파일 도구 100회 이상).

## 설치 프로그램·예약 작업·USB 감시

모두 일반 권한으로 읽기만 하고, 아무것도 지우거나 막지 않습니다.

| 대상 | 읽는 곳 | 주기 | 사건 |
|---|---|---|---|
| 설치 프로그램 | 레지스트리 Uninstall 목록(PC 전체 + 현재 사용자, 제어판 「프로그램 추가/제거」와 같은 출처) | 5분 | INV-NEW-PROGRAM(주의). 버전만 바뀐 업데이트는 알리지 않음 |
| 예약 작업 | `Get-ScheduledTask`(일반 권한으로 보이는 작업) | 5분 | INV-NEW-TASK(주의), 스크립트 실행기(PowerShell·cmd·mshta·rundll32 등)를 부르면 INV-NEW-TASK-SCRIPT(높음). ATT&CK T1053.005 |
| USB·이동식 저장장치 | `Win32_DiskDrive`(USB) + 이동식 드라이브 | 15초 | USB-NEW-STORAGE(주의), 빼면 정보 기록. ATT&CK T1052.001(가능성 20) |

- 처음 실행한 날은 지금 있는 프로그램·예약 작업을 기준 목록(`%LOCALAPPDATA%\djokovic-soc\inventory-baseline.json`)으로 저장만 하고 알리지 않습니다. 그 뒤로는 서버가 꺼져 있던 동안 생긴 것도 다음 실행 때 알립니다.
- USB 는 서버를 켤 때 이미 꽂혀 있던 장치는 알리지 않습니다. 장치 일련번호는 화면과 사건에 내보내지 않습니다.
- 이 PC 실측(2026-10-27): 설치 프로그램 82개, 예약 작업 200개, USB 저장장치 없음. 읽는 데 각각 약 1.2초, 0.4초.

## 사건 기록 보관

사건은 `%LOCALAPPDATA%\djokovic-soc\events.json` 에 30일, 최대 2000건까지 남고 서버를 다시 켜면 되살아납니다. 「사건 기록」 탭 아래에 보관 위치와 마지막 저장 시각이 나옵니다. 오늘이 아닌 사건에는 날짜가 붙습니다. 되살린 사건으로는 팝업·소리를 다시 내지 않습니다. 끄려면 `ON_SOC_HISTORY=0`.

같은 문제가 계속 켜져 있는 설정(예: 자동 로그인)은 새 사건을 쌓지 않고 한 사건의 횟수(×N)만 늘립니다. 이전에는 60초 점검 주기와 같은 사건 묶기 간격(60초)이 겹쳐 1분마다 새 사건이 생기던 문제가 있었고, 묶기 간격을 3분으로 늘려 고쳤습니다.

## PC 켤 때 자동 실행

```
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\autostart.ps1 -Enable          # 켜기(서버 + 미니 창)
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\autostart.ps1 -Enable -NoPip   # 서버만
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\autostart.ps1 -Disable         # 끄기
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\autostart.ps1                  # 상태 보기
```

`desktop/` 폴더가 앱입니다. 관제 서버를 앱 안의 Node(Electron)로 직접 켜므로 Node.js 를 따로 설치하지 않아도 됩니다. 이미 같은 포트에서 관제 서버가 돌고 있으면 그것을 씁니다.

- 포트: 기본 5189. 다른 프로그램(예: 같은 포트를 쓰는 수업 시작 틀 서버)이 쓰고 있으면 5190~5199 중 빈 포트로 저절로 옮기고 알림으로 알려 줍니다. 관제 서버가 아닌 곳은 창에 열지 않습니다(다른 PC에서 5189 를 다른 프로그램이 쓰고 있어 미니 창에 그 프로그램의 오류 JSON 이 뜨던 문제를 고침, 이 PC에서 같은 상황을 만들어 확인).
- 창: 관제 화면 창(흰 Windows 제목 막대 없이 최소화·최대화·닫기 버튼만 화면 위에 겹쳐 그림, 머리 부분을 끌어 옮김), 막대 없는 미니 창. 관제 화면 창을 닫아도 작업 표시줄 오른쪽 알림 영역 아이콘에서 감시가 계속됩니다.
- 알림 영역 아이콘: 색이 미확인 사건 상태를 따릅니다(초록 없음, 노랑 높음·주의, 빨강 긴급, 회색 서버 연결 안 됨). 메뉴에서 관제 화면, PC 보안 점검, 미니 창, 사용 설명서, 로그인할 때 자동 실행, 끝내기를 고릅니다.
- 자동 실행: 설치한 앱을 처음 켤 때 켜집니다(현재 사용자 Run 레지스트리에 `--hidden` 으로 등록, 관리자 권한 없음). 앱을 쓰면 `tools\autostart.ps1` 바로가기는 끄세요(서버가 겹침).
- 만들기(설치 파일): 비밀번호로 암호화한 설치 파일을 만듭니다. 비밀번호는 실행할 때 입력합니다(저장소에 남기지 않음).

```
cd desktop
npm install
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-installer.ps1    # dist\Djokovic 보안 관제 Setup 1.0.0.exe
```

  Windows 개발자 모드가 꺼져 있으면 electron-builder 가 받는 서명 도구 압축 파일(winCodeSign)의 macOS 링크를 풀지 못해 실패합니다. 그때는 `%LOCALAPPDATA%\electron-builder\Cache\winCodeSign\winCodeSign-2.6.0` 에 그 압축을 `darwin` 폴더만 빼고 풀어 두면 됩니다(이 PC에서 그렇게 만들었음).
- 설치 파일 구조: 앱 폴더 전체를 설치 비밀번호로 7z AES-256 암호화(파일 이름까지 암호화)해 넣은 NSIS 설치 프로그램입니다(`desktop/installer/djokovic.nsi`). 설치 프로그램 안에는 비밀번호도 그 해시도 없고, 입력한 비밀번호로 실제로 풀려야 설치됩니다. 7-Zip 으로 설치 파일을 열어도 암호화된 덩어리만 나옵니다. 설치 파일 바이트에 비밀번호와 프로그램 파일 이름(app.asar 등)이 없는 것을 확인했습니다. 안전한 정도는 비밀번호 강도에 달려 있습니다(짧거나 흔하면 대입 공격으로 풀릴 수 있음).
- 설치: 첫 화면에서 설치 비밀번호를 묻고, 맞으면 현재 사용자 폴더(`%LOCALAPPDATA%\Programs\djokovic-soc-desktop`)에 풀어 바탕화면·시작 메뉴 바로가기를 만듭니다. 관리자 권한(UAC) 창은 뜨지 않습니다. 조용한 설치는 `/S /PASSWORD=비밀번호`(없거나 틀리면 종료 코드 5, 아무것도 바꾸지 않음. 이 PC에서 없음·틀림·맞음 세 경우 확인). 예전 방식으로 설치된 것은 자동으로 지우고 새로 설치합니다.
- 지우기: 설정 > 앱 > 설치된 앱 > 「Djokovic 보안 관제」. 프로그램 폴더·바로가기·로그인 자동 실행을 지우고, 사건 기록 등 데이터 폴더(`%LOCALAPPDATA%\djokovic-soc`)는 남깁니다.- Windows 보안 경고(SmartScreen): 이 PC에서 직접 만든 설치 파일에는 인터넷에서 받았다는 표시(Mark of the Web)가 없어서 경고가 뜨지 않습니다(설치 파일에 표시 없음을 확인함). 다른 PC로 보내 인터넷·메신저로 받으면 서명이 없는 프로그램이라 "Windows의 PC 보호" 경고가 뜹니다. 그 경고를 정상적으로 없애려면 코드 서명 인증서(유료, 예: Microsoft Trusted Signing, OV/EV 인증서)로 서명해야 합니다. 경고를 우회하는 방법은 쓰지 않습니다.

## 패치와 자동 업데이트

- 업데이트 설치(1.0.2부터): 설치 파일이 이미 설치된 버전을 읽어 「업데이트: 1.0.1 → 1.0.2」처럼 보여 줍니다(같은 버전이면 다시 설치, 더 새 버전이 깔려 있으면 이전 버전으로 바꿀지 묻고, 조용한 설치에서는 `/ALLOWDOWNGRADE` 없이는 거부·종료 코드 6). 새 버전은 옆 폴더에 먼저 풀고 다 풀린 뒤에만 바꾸므로, 중간에 실패하면 기존 버전이 그대로 남습니다(폴더가 사용 중이면 최대 약 40초 다시 시도, 그래도 안 되면 종료 코드 3 과 함께 원래 앱을 다시 켬). 사건 기록·설정·점검 조치 기록(`%LOCALAPPDATA%\djokovic-soc`)은 건드리지 않고, 업데이트 때 지운 바탕화면 바로가기는 되살리지 않습니다. 조용한 업데이트에서 앱이 켜져 있었으면 끝나고 다시 켭니다. 이 PC에서 1.0.1 실행 중 → 1.0.2 조용한 업데이트가 약 8초에 끝나고 사건 155건이 그대로 되살아나는 것을 확인했습니다.
- 제거 마법사: 설정 > 앱에서 지우거나 알림 영역 아이콘 메뉴의 「프로그램 제거…」를 누르면 마법사가 열립니다. 첫 화면에서 의견 남기기(GitHub 이슈 페이지를 브라우저로 엶)와 후원 안내를 보여 주고, 「사건 기록·점검 기록·설정도 함께 지우기」를 고를 수 있습니다(기본은 남김. Codex 감사 훅 복사본은 Codex 설정이 가리키고 있어 남김). 마침 화면에도 의견 남기기 링크가 있습니다. 후원 안내의 계좌번호는 설치 파일과 공개 저장소에 그대로 들어갑니다.
- 자동 업데이트(1.0.1부터): 앱이 켜지고 30초 뒤, 그다음 6시간마다 GitHub Releases(``alska14/choi-bujang-agent``)의 ``latest.json`` 을 확인합니다. 새 버전이 있으면 알림이 뜨고, 알림 영역 아이콘 메뉴의 「업데이트 설치」를 누르면 받아서 설치 프로그램을 엽니다(설치 비밀번호 입력 필요). 메뉴의 「업데이트 확인」으로 바로 확인할 수도 있습니다.
- 위조 방지: ``latest.json`` 은 업데이트 서명 열쇠(Ed25519)로 서명돼 있고, 앱은 안에 든 공개 열쇠(``desktop/update-key.pub.pem``)로 서명을 확인합니다. 받을 파일 주소는 이 저장소의 Releases 로만 허용하고, 받은 설치 파일의 SHA-256·크기가 ``latest.json`` 과 다르면 실행하지 않습니다. 가짜 정보·변조 파일을 거부하는 것은 테스트로 확인했습니다.
- 개인 열쇠: 배포하는 PC의 ``%LOCALAPPDATA%\djokovic-soc-release\update-signing-key.pem`` 에만 있습니다(저장소에 없음). 잃어버리면 이미 설치된 앱에 업데이트를 보낼 수 없으니 따로 백업하세요.
- 새 버전 내는 순서(``desktop`` 폴더): ``package.json`` 의 ``version`` 을 올림 → ``build-installer.ps1``(설치 비밀번호 입력) → ``publish-release.ps1 -Notes "바뀐 점"``. ``-DryRun`` 이면 올리지 않고 서명까지만 합니다.
- 1.0.0 을 설치한 사람은 자동 업데이트 기능이 없으므로 1.0.1 설치 파일을 한 번 직접 실행해야 합니다. 그 뒤로는 자동으로 알림을 받습니다.

## 화면 성능(렉)

바탕화면 비침(반투명·완전 투과)을 켜면 화면이 초당 약 1프레임으로 끊겼습니다(이 PC, Electron 창 1440×900 실측). 원인은 두 가지였습니다.

1. 판 45개가 각각 뒤 화면을 실시간으로 흐리게(backdrop-filter) 했고, 판 안에 판이 겹쳐 프레임마다 다시 계산됐습니다.
2. 고친 직후에는 흐린 바탕 그림을 CSS 변수에 넣었는데, 작은 애니메이션이 돌 때마다 그림을 다시 해석해서 여전히 느렸습니다.

지금은 바탕화면 그림을 처음 한 번만 흐리게 그려(반투명 26px, 완전 투과 3px) 작은 JPEG 로 만들어 body 에 바로 넣고, 판은 반투명 색만 씁니다. 실시간 흐림은 가끔 뜨는 알림·서랍에만 남겼습니다. 결과: 반투명·완전 투과·꺼짐 모두 60fps(긴 작업 0건).

## 위협 인텔리전스

- 수집: 침해지표(IP, CIDR(/8 이상), 도메인(`*.` 와일드카드), SHA-256, 프로세스 이름, 경로 조각)를 직접 입력하거나 텍스트·STIX 2.1 파일로 가져옵니다. 이 앱에는 기본으로 들어 있는 위협 데이터가 없습니다.
- 공유: STIX 2.1로 내보냅니다(TLP 표시 포함). 프로세스·경로·와일드카드 도메인은 내보내지 않습니다. TAXII는 지원하지 않습니다.
- 탐지: 현재 TCP 연결, DNS 캐시, 프로세스 이름·명령줄, 실행 파일 해시, 에이전트 명령을 침해지표와 TTP 규칙(13개, 알려진 패턴 일치)으로 대조합니다. 「시험 탐지」로 파이프라인이 도는지 확인합니다.
- 반영: 사건을 「악성 확정」으로 판정하면 지표가 추가되고, 「오탐」이면 허용 목록에 들어가 같은 사건이 다시 올라오지 않습니다.
- ATT&CK 연결은 2026-10-27 attack.mitre.org(v20)에서 확인한 기법 목록만 씁니다. 규칙과 기법의 연결은 가능성이며 확정이 아닙니다.

## 한계

- 폴더 변경 감시는 생성·수정·삭제·이름 변경만 감지하며 파일을 열어 읽은 것은 감지하지 못합니다.
- 호스트 점검의 기준선(방화벽 규칙 수, 계정 목록, VPN, 주변 장치)은 앱을 켠 뒤 첫 점검에서 잡습니다. 앱을 다시 켜면 초기화되고, 꺼져 있던 동안의 변경은 모릅니다. 설치 프로그램·예약 작업만 기준 목록을 파일로 남겨 꺼져 있던 동안의 변경도 잡습니다.
- 프로세스 명령줄은 일반 권한으로 약 절반 정도만 보였습니다(이 PC 실측).
- 이 PC에서 실제로 관측된 것: 자동 로그인이 켜져 있고, 「비밀번호가 필요함」 설정이 꺼진 활성 계정이 1개 있습니다. 둘 다 주의 사건으로 올라옵니다. 앱의 오류가 아니라 이 PC 설정에 대한 관측입니다.

## 막대 없는 데스크톱 미니 창(Electron)

브라우저 PiP 창 위의 주소 막대는 브라우저가 강제로 붙이는 것이라 없앨 수 없습니다. 막대 없이 항상 다른 창 위에 떠 있는 창이 필요하면 데스크톱 미니 창을 씁니다.

```
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-pip.ps1 -Install   # 처음 한 번(Electron 약 370MB를 pip-desktop\node_modules 에 내려받음)
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-pip.ps1            # 그다음부터
```

- 관제 서버(`tools\start-final.ps1`)가 켜져 있어야 합니다. 꺼져 있으면 안내를 보이고 5초마다 다시 연결합니다.
- 판 아무 곳이나 끌면 창이 옮겨지고, 가장자리를 끌면 크기가 바뀝니다. 위치·크기는 기억됩니다.
- 위쪽에 마우스를 올리면 「◐−」「◐+」(판 투명도), 「✕」(닫기) 버튼이 나옵니다.
- 보여 줄 정보와 모양은 관제 화면의 「PiP·미니 창」 설정을 그대로 따릅니다.
- 이 창은 관제 서버 주소만 열고 다른 주소로 이동하거나 새 창을 여는 것은 막습니다. 페이지에 Node 기능을 주지 않습니다(contextIsolation, sandbox).
- Electron 버전: 45.0.0. 제공 서버와 시작 틀의 `package.json` 은 바꾸지 않았고, Electron 은 `pip-desktop` 폴더에만 설치됩니다(저장소에는 `node_modules` 가 올라가지 않음).
