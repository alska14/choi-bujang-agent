# 완성본 시연 순서와 정리 (Djoković, 마지막 총공세)

이 문서는 최종 앱(「내 PC 상태」)을 시연하는 순서와, 되는 것·안 되는 것·확인 불가인 것, 그리고 그 근거를 구분해 적은 정리입니다. 확인하지 않은 것을 됐다고 쓰지 않습니다.

- 릴리스 구분: **검증 중인 버전**. v1.0이 아니며 실제 운영 인증이 아닙니다.
- 기준 코드 커밋: `99e73fa71f120c8d8f3975395a281e3dda622cce` (브랜치 `final-app`). 이 문서는 그 뒤에 추가한 문서 전용 커밋에 들어 있으며, 코드(`src`, `pc-status`, `tools`, `test`, `student`, `public`)는 기준 커밋과 같습니다.
- 확인 날짜와 환경: 2026-10-27, Windows 11 Pro 10.0.26100, Node.js v24.21.0, Windows PowerShell 5.1, 일반 사용자 권한(관리자 아님).
- 수행 주체: 아래 실행·화면 확인은 학생의 요청으로 AI 코딩 도구(Claude Code)가 같은 PC에서 수행한 것입니다. 학생이 직접 눌러 확인한 것은 이 문서에 없습니다.

## 1. 증거 표시

| 표시 | 뜻 |
|---|---|
| 실측 | 이 PC에서 그 시각에 읽은 값. 시각이 바뀌면 값도 바뀝니다 |
| 화면 확인 | 실제 브라우저 화면에서 확인함 |
| 실행 기록 | 명령을 실행해 출력과 응답을 확인함 |
| 모의 시험 | 가짜 데이터로 코드를 호출함. 실제 PC 값이 아님 |
| 코드 확인 | 파일을 읽고 확인함. 실행하지 않음 |
| 미확인 | 하지 않았거나 환경이 없어 확인하지 못함 |

이 문서와 화면에는 설명용 예시 값이 없습니다. 숫자는 모두 "실측"으로 표시한 것입니다.

## 3. 핵심 기능 3가지와 시연 순서

시연 전에 서버를 켭니다: `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-final.ps1` (자세한 안내: `docs/QUICK_START.md`). 브라우저에서 `http://127.0.0.1:5189/pc-status`를 엽니다.

| 순서 | 핵심 기능 | 시연 | 기대하는 것 | 확인 |
|---|---|---|---|---|
| 1 | 지금 상태 4칸 | 「다시 조회」를 두 번 누름 | 첫 조회는 CPU만 "확인 불가(첫 측정)"와 "다음에 할 일", 나머지 3칸은 실측. 둘째 조회는 4칸 모두 실측이고 위쪽 표시가 "다시 조회 성공" | 화면 확인 |
| 2 | 시간에 따른 변화 | 값을 CPU·메모리·디스크로 바꿔 보고 조회를 몇 번 더 함 | 막대 그래프, 직전 대비 증감, 최소·최대. 확인 불가였던 회차는 짧은 주황색 막대 | 화면 확인 |
| 3 | 최근 기록과 연결·이벤트 | 아래 영역을 봄 | 최근 조회 표, 네트워크 어댑터, 방화벽 프로필, Windows 기록 건수, 그리고 "SDP 미연결"이 별도 칸으로 표시됨 | 화면 확인 |

시연 중 실패 장면도 보여 줍니다: 서버를 끈 채 「다시 조회」를 누르면 세 값이 "확인 불가"와 "요청 실패 시각", "서버를 켜라"는 안내로 바뀌고 이전 값이 남지 않습니다. [화면 확인]

## 4. 네 가지 관점으로 본 결과

### 4-1. 기능 작동: 핵심 기능이 이 PC에서 끝까지 동작하는가

- 4칸 조회, 추이 그래프, 기록 표, 연결·방화벽·Windows 기록 조회가 이 PC에서 끝까지 동작했습니다. [화면 확인, 실행 기록]
- 이 PC에서 실측한 값(2026-10-27 오전, 시각마다 달라짐): CPU 4.8%~25.1%(조회 간격에 따라 흔들림), 메모리 10.3~10.6 GB 사용(전체 15.8 GB), 디스크 C: 208.8~208.9 GB 남음(전체 465.6 GB), 방화벽 Domain·Private·Public 3개 모두 켜짐, 최근 24시간 Windows 기록 System 오류 28건·경고 18건, Application 오류 2건·경고 4건, 외부 네트워크 어댑터 3개(모두 IPv4 보유). [실측]
- 모의 시험 28개 통과(CPU 계산, 메모리·디스크 검증, 추이, 읽기 실패 처리, 서버 경로 분기). [모의 시험]
- 기능 개수로 평가받으려 하지 않고, 위 3가지를 끝까지 동작시키는 데 집중했습니다.

### 4-2. 근거 정직성: 실측, 예시, 확인 불가를 구분하는가

- 화면의 모든 값에 "실측"·"확인 불가"·"조회 전"·"조회 중" 표시와 잰 시각이 붙습니다. 예시 값으로 대신 채우지 않습니다. [화면 확인]
- 읽지 못한 항목은 이유와 "다음에 할 일"과 함께 "확인 불가"로 남깁니다. 권한 없음은 관리자 권한을 올려서 읽지 않고 그대로 확인 불가로 둡니다. 이 PC에서는 권한 오류가 실제로 나지 않아, 권한 없음·시간 초과 표시는 응답을 가로채 화면을 확인했습니다. [모의 시험, 화면 확인]
- Windows 기록 건수는 "침해나 공격 탐지 결과가 아니라 경고·오류 기록의 개수"라고 화면에 적었습니다. 방화벽의 기본 동작이 "지정 안 됨"일 때 허용·안전으로 읽지 않도록 설명을 붙였습니다. [화면 확인]
- SDP 연결은 "미연결"로 따로 표시하고, PC 조회 성공과 섞지 않습니다. [화면 확인, 모의 시험]
- IP 주소와 MAC 주소는 화면과 응답에 싣지 않습니다. [실행 기록, 모의 시험]

### 4-3. 사용 편의: 처음 보는 사람이 화면과 오류 안내를 보고 쓸 수 있는가

- 첫 화면에서 할 일이 「다시 조회」 하나로 분명하고, 조회 중에는 버튼이 "조회 중…"으로 바뀌어 눌러지지 않으며 칸마다 "조회 중" 표시가 나옵니다. [화면 확인]
- 실패한 칸마다 이유와 "다음에 할 일"이 나옵니다. 위쪽 표시는 "다시 조회 성공"·"일부 확인 불가"·"조회 실패" 중 하나이며 글자로 구분됩니다(색만으로 구분하지 않음). [화면 확인]
- 명암비: 화면 텍스트 97개를 계산해 기준 미달 0건. [실행 기록]
- 키보드: 모든 조작이 `button`과 링크이고 Tab 순서가 자연스럽습니다(건너뛰기 → 돌아가기 → 다시 조회 → 자동 조회 → 그래프 값 선택). 실제 키 입력으로 눌러 보는 것은 시험 도구의 한계로 하지 못했습니다. [코드·순서 확인, 키 입력은 미확인]
- 설치형 앱에서 이 화면이 보이는지는 확인하지 못했습니다. [미확인]

### 4-4. 재현 가능성: 실행 안내와 패키지만으로 같은 결과를 다시 만들 수 있는가

- 실행 안내(`docs/QUICK_START.md`)를 새 빈 폴더에서 그대로 따라 해 4단계(내려받기, 실행, 화면, 끄기)와 막혔을 때 표를 확인했습니다. 확인 중 안내의 틀린 곳(위치가 틀렸을 때의 증상)을 하나 찾아 고쳤습니다. [실행 기록]
- 22단계에서 새 폴더 재현 기록(`docs/REPRODUCTION_RECORD.md`)을 남겼습니다.
- GitHub에 `final-app` 브랜치를 올린 뒤 안내의 1단계 GitHub 명령을 새 빈 폴더에서 그대로 실행해, 같은 커밋이 받아지고 시험 28개가 통과하고 서버가 뜨는 것을 확인했습니다(2026-10-27). [실행 기록]
- 한계: 안내를 따라 한 것은 AI 도구이며 처음 보는 사람이 아닙니다. 포장 패키지는 만들지 못했습니다(6절). [미확인]

## 6. 6일차 포장 상태: 준비가 필요한 항목

포장은 하지 못했습니다. 안내대로 우회하지 않고 담당자 준비가 필요한 항목으로 기록합니다.

| 확인한 것 | 결과 |
|---|---|
| `npm run package-app` | `Missing script: "package-app"`. `package.json`에는 `start`, `demo`, `check`만 있음 [실행 기록] |
| 과제 폴더 전체에서 `package-app`, `APP_PACKAGE_MANIFEST`, `PROVIDED_RUNTIME_NOT_INSTALLED` 검색 | 내가 쓴 문서 외에는 흔적 없음 [실행 기록] |
| 승인된 실행 환경, 운영 앱 승인 키 | 이 PC에서 확인할 방법이 없음. 요청하거나 만들지 않음 [미확인] |
| Inno Setup(설치 프로그램 방식) | 이 PC에 없음(PATH와 설치 목록에서 0건). 설치는 PC 변경이라 학생의 허락 없이 하지 않음 [실행 기록] |
| `student/appearance.json` | 이 저장소에 없음. 형식을 모르므로 만들지 않음 [실행 기록] |

필요한 것: ① 포장 도구(`package-app`)와 승인된 실행 환경, 앱 승인 키를 가진 시작 틀 업데이트(담당자 안내), ② 설치 프로그램 방식을 고른다면 Inno Setup 설치에 대한 학생의 결정. 안내에 따르면 설치 프로그램은 포장 결과를 담아 옮길 뿐이고, 받는 PC에도 제공 실행 환경이 있어야 합니다. `setup.exe`의 SHA-256 해시는 만들지 않았으므로 기록하지 않습니다.

## 7. 아직 안 되거나 확인 불가인 것

- 실제 SDP 서버 연결, 계정 연결, AI 연결·설명, 조치 집행: 연결 설정이 없어 안 됩니다(보안 앱의 "연결 없음"). 19단계 실집행은 준비되지 않았습니다.
- 「내 PC 상태」가 설치형 앱에 반영되는지: 이 구현은 `final-app.mjs`와 `pc-status/`의 새 파일이라, 안내가 말하는 "완성본에 반영되는 작업 위치"(`student/extension.mjs`, `student/appearance.json`)에 들어 있지 않습니다. 설치형 앱은 검증된 제공 화면을 사용하므로 이 화면이 그대로 보인다고 가정하지 않으며, 승인된 실행 환경에서 확인하지 못했습니다. [미확인]
- 작업 관리자 값과의 일치: Windows의 "사용 가능 메모리" 기준과 같은지 비교하지 않았습니다. [미확인]
- 키 입력으로 눌러 보는 조작, 장시간 자동 조회, 다른 PC·다른 계정, PowerShell 7·macOS·Linux: 확인하지 못했습니다.
- 관리자 권한이 있어야 읽히는 항목은 읽지 않았고, 설정을 바꾸는 시험, 공격·침해를 흉내 내는 시험은 하지 않았습니다.
