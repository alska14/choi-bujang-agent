# 빠른 실행 안내 (처음 보는 사람용)

이 안내만 보고 내 PC에서 「내 PC 상태」 화면을 열어 보는 방법입니다. 걸리는 시간은 5분 안팎입니다. 더 자세한 설명과 확인 기록은 `STUDENT_RUNBOOK.md`에 있습니다.

## 준비물 (둘 다 확인)

| 필요한 것 | 확인 명령(PowerShell) | 이렇게 나오면 됩니다 |
|---|---|---|
| Node.js 22~24 (24.19.0 권장) | `node --version` | `v22.x`, `v23.x`, `v24.x` 중 하나. 없으면 https://nodejs.org 에서 LTS를 설치한 뒤 PowerShell 창을 새로 엽니다 |
| Git | `git --version` | `git version ...`. 없으면 https://git-scm.com 에서 설치합니다 |

관리자 권한은 필요 없습니다. 이 안내의 어떤 단계도 프로그램을 설치하거나 PC 설정을 바꾸지 않습니다(위 준비물 설치는 제외).

## 1단계. 내려받기

새 PowerShell 창을 열고 한 줄씩 실행합니다. 폴더 `choi-bujang-agent`가 현재 위치에 새로 생깁니다.

    git clone --branch final-app https://github.com/alska14/choi-bujang-agent.git
    cd choi-bujang-agent\on-client

제출한 커밋(40자리)으로 정확히 맞추려면 이어서 `git checkout <커밋 해시>`를 실행합니다.

## 2단계. 실행

    powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-final.ps1

이 창에 아래 문구가 나오면 켜진 것입니다. 이 창은 닫지 말고 그대로 둡니다.

    보안 앱: http://127.0.0.1:5189/
    내 PC 상태: http://127.0.0.1:5189/pc-status
    서버가 응답한 것만 확인했습니다. ...

`-ExecutionPolicy Bypass`는 이 한 번의 실행에만 적용되며 PC 설정을 바꾸지 않습니다.

## 3단계. 화면 열기

브라우저 주소창에 `http://127.0.0.1:5189/pc-status`를 입력합니다.

1. 처음에는 네 칸(CPU, 메모리, 디스크, 방화벽)이 "조회 전"입니다.
2. 「다시 조회」를 누릅니다. 이때 CPU 칸이 "확인 불가"인 것은 정상입니다. CPU는 두 번 읽어 비교해야 나오기 때문입니다.
3. 몇 초 뒤 「다시 조회」를 한 번 더 누릅니다. 네 칸 모두 "실측"과 숫자가 보이고, 위쪽 표시가 "다시 조회 성공"이 되면 성공입니다.
4. 화면 아래의 "연결·방화벽·Windows 기록"에서 "SDP 미연결"이 따로 보이는 것도 정상입니다. 이 앱은 회사 시스템(SDP)에 연결하지 않은 상태로 실행됩니다.

## 4단계. 끄기

실행한 PowerShell 창에서 `Ctrl+C`를 누릅니다. 다시 켜려면 2단계 명령을 다시 실행합니다.

## 막혔을 때

| 보이는 것 | 원인 | 할 일 |
|---|---|---|
| "앱 폴더가 아닙니다" | 현재 위치가 `on-client`가 아님 | `cd`로 `choi-bujang-agent\on-client`에 들어가 2단계를 다시 실행 |
| "Node.js 가 없습니다" 또는 "Node.js 22~24 에서 실행합니다" | Node.js가 없거나 버전이 범위 밖 | 준비물의 `node --version`을 확인하고 설치 후 PowerShell 창을 새로 엽니다 |
| "포트 5189 를 다른 프로그램이 쓰고 있습니다" | 다른 프로그램이 같은 번호를 씀. 그 프로그램은 끄지 않습니다 | 명령 끝에 ` -Port 5190`을 붙여 실행하고, 브라우저 주소의 `5189`도 `5190`으로 바꿉니다 |
| "앱 서버가 20 초 안에 뜨지 않았습니다" | 서버가 시작하지 못함 | 같은 창의 메시지를 확인합니다 |
| 방화벽·Windows 기록 칸이 "확인 불가"이고 "관리자 권한이 필요한 항목" 안내가 나옴 | 이 계정으로는 읽을 수 없는 항목. 이 앱은 권한을 올려서 읽지 않습니다 | 정상 동작입니다. 값을 바꾸지 않고 "확인 불가"로 둡니다 |
| 한 칸이 "확인 불가"이고 "서버가 켜져 있는지 확인" 안내가 나옴 | 서버가 꺼졌거나 요청이 실패 | 2단계 창이 켜져 있는지 확인하고 「다시 조회」를 누릅니다 |
| 보안 앱(`http://127.0.0.1:5189/`)에 빨간 "연결 없음" 안내가 보임 | 회사 시스템 연결 설정이 없는 기본 상태 | 정상입니다. 「내 PC 상태」 화면과 별개입니다 |

예제 자료로 보안 앱 화면을 보고 싶으면 2단계 명령 끝에 ` -Demo`를 붙입니다. 예제 값은 실제 연결 결과가 아닙니다.
