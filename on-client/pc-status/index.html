    조치 기록
    바꾸기 전 값을 남겨 두어 되돌릴 수 있습니다
    
            
      
          
      
        
      

        
      
          
      
            
      
              
              
      
                
      이 탭은 "나쁜 것 목록"과 내 PC를 계속 대조하는 곳입니다
      
                
      알려진 나쁜 주소·파일·프로그램 이름 목록(침해지표, IOC)과 공격자가 자주 쓰는 명령 수법(TTP)을, 이 PC의 지금 연결과 실행 중인 프로그램에 15초마다 맞춰 봅니다. 하나라도 걸리면 사건으로 알립니다.
      
                
      처음에는 목록이 비어 있습니다(이 앱에는 미리 넣어 둔 위협 데이터가 없습니다). 보안 공지나 동료에게 받은 목록을 넣으면 그때부터 대조합니다. 공격 수법 규칙 13개는 기본으로 들어 있습니다.
      
              
      
            
      
            
        
              
      1. ① 목록 넣기아래 입력란에 IP·도메인 등을 적거나, 받은 목록을 붙여 넣습니다.
        2. 
              
      2. ② 주고받기내 목록을 표준 파일(STIX)로 내보내 다른 사람과 나눕니다.
        3. 
              
      3. ③ 자동 대조15초마다 연결·프로그램과 맞춰 보고, 걸리면 알림이 뜹니다.
        4. 
              
      4. ④ 판정 반영걸린 사건을 "악성 확정" 또는 "오탐"으로 정하면 목록이 스스로 다듬어집니다.
        5. 
            
      
            
      처음이면 아래 ③의 「탐지 시험」을 눌러 보세요. 내 PC 주소(127.0.0.1)를 일부러 나쁜 주소로 등록해 실제로 걸리는지 보여 줍니다(시험 표시가 붙고 실제 위협이 아닙니다).
      
            
      용어 풀이
              
      
                
      IOC(침해지표)
      공격에 쓰인 것으로 알려진 IP 주소, 도메인, 파일 지문(SHA-256), 프로그램 이름 같은 "흔적".
      
                
      TTP(전술·기법·절차)
      공격자가 쓰는 방법. 예: 백신 끄기, 복구 지점 지우기, 숨긴(인코딩한) PowerShell 실행.
      
                
      ATT&CK
      MITRE가 정리한 공격 수법 사전. 각 수법에 T1059 같은 번호가 붙어 있습니다.
      
                
      STIX
      위협 정보를 주고받는 표준 파일 형식(JSON).
      
                
      TLP
      정보를 어디까지 나눠도 되는지 표시(clear·green·amber·red).
